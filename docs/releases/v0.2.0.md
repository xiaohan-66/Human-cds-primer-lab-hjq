Exact-CDS candidate yield: Studio 38/60, Primer3 25/60. Different acceptance filters prevent interpreting yield as comparative accuracy. Studio adaptive returned candidates for 57/60 in a separate task. 565 returned pairs passed coordinate/sequence/basic-constraint checks.

Official Primer-BLAST comparison and wet-lab validation remain pending. No specificity accuracy, PCR success rate or calibrated threshold is claimed. The online deployment may differ from this source snapshot.
