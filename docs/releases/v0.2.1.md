# Primer Studio 0.2.1 · Research preview

- Add 57 completed official NCBI Primer-BLAST supplied-pair reports from the original 60-gene panel. All 57 include the expected accession product; 49 also report potentially unintended products. Three genes had no Studio candidate. Two initial HTTP 502 failures succeeded on retry and are retained in the archive.
- Add 60 explicitly post-hoc curated design examples, selected from 67 eligible genes among 157 evaluated genes. All three design settings return candidates for these selected genes by construction. This is not a new general-performance claim; original benchmark results remain public.
- Center README tables, shorten the introduction, and update repository links to Lingxu-primer-studio.
- Preserve raw reports, design results, provenance, and offline parser integrity checks.

The official review covers supplied Studio adaptive leads, not de novo Primer-BLAST design yield or a matched accuracy benchmark of Studio's pairing engine. A-D grades remain heuristic and uncalibrated; no wet-lab success is claimed.
