# Quality calculation, version 1

New batch designs use SantaLucia 1998 DNA nearest-neighbor enthalpy/entropy parameters with terminal and symmetry corrections, SantaLucia entropy salt correction, and von Ahsen Mg-to-monovalent approximation. Default calculation conditions: 50 mM monovalent, 1.5 mM magnesium, 0.6 mM total dNTP, 50 nM effective oligo concentration. No DMSO, polymerase-specific correction or experimental guarantee. DNA concentration uses C/4 for nonsymmetric duplexes and C for self-complementary sequences.

Reference: https://primer3.org/manual.html and https://biopython.org/docs/latest/api/Bio.SeqUtils.MeltingTemp.html . Independent golden values in tests/thermo-reference-fixture.json were generated using Biopython 1.88 DNA_NN3, saltcorr=5.

Secondary structure assessment is an exact contiguous Watson-Crick complementarity screen, NOT a thermodynamic folding/free-energy model. Hairpin loop minimum 3 nt; warn for stems >=4 bp, self/heterodimer runs >=6 bp, terminal-involving runs >=4 bp, >=4 GC in the last 5 nt, or terminal homopolymer >=3 nt. Thresholds are transparent screening heuristics, not validated experimental cutoffs. No bulges or mismatched stem prediction.

All enumerated oligos pass 18–25 nt, configured Tm and deltaTm<=3. Unary structural risk is considered when retaining preselection candidates. Pairwise risk is assessed in that retained pool. Batch ranking considers structural risk level, exact paired hits in already retrieved same-gene transcripts, risk count, basic warnings (including homopolymers >=4 and dinucleotide repeats >=4), deltaTm in 1 C bands, then extra UTR. Near-identical deltaTm is no longer an objective in itself. Selection favors different binding positions for alternatives. Local isoform screening is limited to retrieved transcripts, uses exact binding and <=50 kb products, and is not a specificity verdict. This is not a global exhaustive thermodynamic optimum.

Original stored results retain their original values; they must be recomputed to use this model. Chemistry and assessment are exported with new results.

BLAST products are classified using NCBI GenBank GeneID annotations, cached for 7 days. No gene identity is inferred from product names. Missing/ambiguous annotations, species metadata omissions and capped result lists remain explicitly incomplete. Absence of other observed products never means specificity passed.

## Verification update, September 2026

Every new design independently checks the exact F sequence and reverse-complement R at their declared transcript coordinates, inward orientation, length, and complete CDS coverage (or explicit exact-mode stop removal). Submission rechecks against the server's stored versioned transcript, including old designs, and stores an immutable target-check snapshot. Local target matches are never inserted into remote BLAST product lists. Thus a remote omission and a correct local target can coexist without a misleading failure or pass.

New public BLAST requests use refseq_rna with ENTREZ_QUERY=txid9606[ORGN], 500 retained hits/query, and at most 400 query bases per chunk. This parameter is used by Biopython qblast but is absent from the currently documented NCBI Common URL API contract. It is treated as a compatibility path, not a guaranteed API: every report must echo the exact filter and all returned descriptions must be human with known taxonomy before scope is marked confirmed. Missing/contradictory evidence fails closed. Legacy jobs retain their original scope and 100-hit cap. No genomic coverage, no exhaustive near-match alignment, and no multiplex cross-pair screen is claimed. Full-length ungapped <=2 mismatches with exact last 5 nt remains the current paired-hit rule; partial HSPs are not evidence of absence. All capped results remain incomplete even when the tail contains weak local matches.

The comparison panel uses the newest result per current sequence, compares only tested candidates, and exposes target validity, known other-gene/unknown/same-transcript/same-gene products and completeness. It does not silently mutate stored designs. Incomplete comparisons are provisional. CSV exports include target evidence and scope. Old designs require recomputation for the new quality ranking; old BLAST records require a new verification request for human-restricted retrieval.

Live checks: SRPK1 human-filter probe RID A1BGU8J5014 recovered both target hits previously lost to all-species truncation. Five-gene regression RID A1C2GDG9014 recovered expected products for SRPK1, SRSF4, SUMO2, TARDBP and TRIM37, with all ten reports echoing the human filter, all returned descriptions human, and 249369 database sequences reported. All reached the 500-hit cap, so none is presented as exhaustive specificity clearance. Real transcript fixtures and deterministic negative/boundary tests are in tests/verification-upgrade.test.mjs.

A dedicated versioned human RNA/genome BLAST service remains infrastructure work: the current 128 MB Worker is not a standalone BLAST host. Public-service queue/rate limits remain in force; this update does not claim production throughput for thousands of targets.
